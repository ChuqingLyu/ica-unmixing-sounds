Unmixing Sounds

A small ICA demo: separating mixed sounds, the cocktail party problem

View source on GitHub

About this project

I built this to help K-12 learners see an idea from machine learning that they normally can't see. When several sounds are recorded together, every microphone hears a blend of all of them. Independent Component Analysis (ICA) can pull the sounds apart again, using only the mixtures.

This connects to my research on making AI explainable to kids through hands-on, constructionist interaction. Instead of reading formulas, learners change the mix, listen, press a button, and compare what comes out with what went in.

It is a standalone project, not a pre-lesson: everything you need is on this page.

1 · Sources

Three sounds, each 4 seconds long, made right here in your browser.

2 · Microphones (mixtures)

Each microphone hears all three sounds at once. The numbers say how loud each sound is at each microphone (0 to 1).

3 · ICA output

ICA only gets the three microphone recordings. It never sees the original sounds.

Note: ICA can't know the original order or loudness (or sign), so components may come out shuffled or flipped. To help you compare, each one shows the source it matches best.

How it works

Each microphone recording is a weighted sum of the sources: x = A · s, where A holds the mixing weights. ICA looks for a way to recombine the recordings so that the results are as statistically independent, and as non-Gaussian, as possible, because mixing real sounds makes them look more Gaussian. PCA is different: it finds uncorrelated directions of maximum variance, and that alone is not enough to unmix the sounds. FastICA works in three steps: it centers the data (subtracts the mean), whitens it (rescales so the signals are uncorrelated with equal variance), and then repeatedly updates a set of unmixing directions with a tanh rule until they stop changing.
